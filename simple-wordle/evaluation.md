## 1. Did the project meet the requirements?

The game has a five-letter guessing grid, six attempts, colour feedback and win/lose messages. It also has a timer as an extra feature. The main limitation is that the player can enter any five-letter combination rather than only real words.

A framework such as React could help with a much bigger interactive application, but would add extra setup for a small beginner project.
