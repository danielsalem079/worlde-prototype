# Wordle Game - Evaluation and Review

1. Critical Evaluation of the Project

The main aim of my project was to create a web-based Wordle game using HTML, CSS and JavaScript. The game needed to allow players to guess a hidden five-letter word within six attempts while receiving feedback on whether their letters were correct. I also needed to implement at least one additional feature beyond the basic requirements.

Overall, I think the project has been successful in meeting its main objectives. The game includes a guessing system, a six-attempt limit, coloured letter feedback, win and lose messages, and a restart button. I also included a timer as my additional feature, which allows players to see how long they take to complete the game.

Strengths

One of the main strengths of my game is that it is simple and easy to understand. The instructions explain how to play, and the green, yellow and grey colours help players identify which letters are correct. This makes the game suitable for people who have not played Wordle before.

Another strength is the input validation. The JavaScript checks that players enter exactly five letters before accepting their guess. This prevents incorrect inputs from affecting the number of attempts and helps the game work more reliably.

The timer is another useful feature because it adds an extra challenge. Players can try to complete the game faster, making it more interesting than simply guessing the correct word.

I also think using separate HTML, CSS and JavaScript files was a good decision because it made the project easier to organise. For example, I could change the appearance of the game without changing the JavaScript functions.

Limitations

Although the game meets its main requirements, there are still some limitations.

One limitation is that players can enter any combination of five letters, even if it is not a real English word. This makes the game less challenging compared to the original Wordle because players can enter random letters. In the future, I would improve this by adding a dictionary or list of valid words.

Another limitation is the small selection of possible hidden words. As the player continues restarting the game, they may eventually recognise words that have appeared previously. A larger word list would improve replayability.

The game also does not save previous results or the player's fastest completion time. This means the timer is useful during gameplay but does not allow players to compare their results across different sessions.
2. Reflection on the Development Process

During the development of my Wordle game, I had to make decisions about the design, functionality and organisation of the project.

I decided to use three separate files: index.html, style.css and script.js. This made it easier to understand what each part of the project was responsible for. HTML created the structure of the game, CSS controlled its appearance, and JavaScript handled the game logic and interactions.

I also used GitHub to manage the project files and record changes through commits. This was useful because it provided a history of the development work and allowed me to keep track of changes to the code.
